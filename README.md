Skyharbor Flight is an original browser flight game: fly the Kestrel-7 out of Skyharbor Field through golden rings, land on three island strips, or reach the storm beacon — with throttle, fuel and damage turning every sortie into decisions.

## Run it

```sh
npx serve game
```

Open the served game/index.html in desktop Chrome. Fly with arrow keys or WASD, throttle with Shift or the mouse wheel, steer with the mouse, brake with Space, pause with P.
